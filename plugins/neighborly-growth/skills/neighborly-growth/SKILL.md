# Neighborly Growth

## Canonical skill routing

Use the matching canonical workflow under `.agents/skills/<skill-name>/SKILL.md`. Read that file completely before acting. Available routes are:

- Research and strategy: `market-research`, `customer-research`, `provider-research`, `competitor-analysis`, `micro-market-selection`, `positioning`, `launch-strategy`, `red-team-review`.
- Acquisition and sales: `provider-acquisition`, `sales-qualification`, `outreach-personalization`, `offer-design`, `community-growth`, `referral-program`.
- Content and discovery: `content-strategy`, `social-content`, `local-seo`, `programmatic-seo`.
- Lifecycle and optimization: `crm-lifecycle`, `onboarding-optimization`, `retention-analysis`, `experiment-design`.
- Marketplace measurement: `analytics-scorecard`, `marketplace-liquidity`, `marketplace-unit-economics`.
- Governance: `casl-compliance`, `trust-safety-verification`.

For cross-functional requests, apply the smallest set in this order: evidence gathering, market/economic decision, execution design, compliance/safety review, measurement, then red-team review.

## Operating boundaries

- Follow `docs/MARKETING-OPERATING-MODEL.md` and its legal, safety, money/action, and human approval gates.
- Treat research status separately from KYC approval, consent, or permission to contact.
- Produce drafts and plans locally. Do not send messages, publish, spend, modify CRM data, connect accounts, or transmit customer/provider data externally.
- This plugin contains no app, MCP server, or credential. GitHub writes, external connections, and production actions require explicit approval immediately before execution.
