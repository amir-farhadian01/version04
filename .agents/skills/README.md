# Neighborly Growth Skill Catalog

These project-scoped Agent Skills use Antigravity's `.agents/skills/<name>/SKILL.md` convention. Each skill is independently discoverable through YAML metadata and defines inputs, procedure, output, quality, failure, and escalation rules.

## Research and decisions

`market-research`, `competitor-analysis`, `micro-market-selection`, `customer-research`, `provider-research`, `positioning`, `offer-design`, `red-team-review`

## Marketplace and launch

`marketplace-liquidity`, `marketplace-unit-economics`, `launch-strategy`, `community-growth`, `provider-acquisition`, `sales-qualification`, `trust-safety-verification`

## Content and lifecycle

`local-seo`, `programmatic-seo`, `content-strategy`, `social-content`, `outreach-personalization`, `crm-lifecycle`, `onboarding-optimization`, `referral-program`, `retention-analysis`, `casl-compliance`

## Measurement

`experiment-design`, `analytics-scorecard`

The three approval gates and shared context protocol are canonical in [`docs/MARKETING-OPERATING-MODEL.md`](../../docs/MARKETING-OPERATING-MODEL.md). Skills do not grant permission to execute external or high-risk actions.
