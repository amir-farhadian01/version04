# Neighborly Growth Agents

Google Antigravity is the primary runtime for these nine role definitions. The [GTM Orchestrator](gtm-orchestrator/AGENT.md) selects only the specialists needed for a founder objective; specialists return evidence-backed artifacts for synthesis.

| Agent | Primary ownership |
|---|---|
| [gtm-orchestrator](gtm-orchestrator/AGENT.md) | Delegation, synthesis, disagreement resolution, gates |
| [market-intelligence](market-intelligence/AGENT.md) | External market and competitor evidence |
| [positioning-brand](positioning-brand/AGENT.md) | Positioning, messaging, brand, offer hypotheses |
| [marketplace-growth](marketplace-growth/AGENT.md) | Liquidity, growth loops, unit economics |
| [launch](launch/AGENT.md) | Readiness and supply-first launch sequencing |
| [content-seo](content-seo/AGENT.md) | Supply-backed content and local discovery |
| [sales-supply](sales-supply/AGENT.md) | Provider qualification and compliant pipeline |
| [crm-lifecycle](crm-lifecycle/AGENT.md) | Activation, retention, and referral journeys |
| [analytics-experiments](analytics-experiments/AGENT.md) | Definitions, scorecards, and experiment integrity |

Shared procedures live in [`../skills/`](../skills/). Trust & Safety and Red Team are skills, not permanent agents. All roles follow [`docs/MARKETING-OPERATING-MODEL.md`](../../docs/MARKETING-OPERATING-MODEL.md).
