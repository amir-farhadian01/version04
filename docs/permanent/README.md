# 📁 docs/permanent/

**This folder is for temporary files only:**
- Agent prompts
- Test scripts
- Scratch/temp files
- Session-based artifacts

**⚠️ This folder is cleaned after every work session.**
Do not store permanent documentation here — use the parent `docs/` directory instead.

Permanent documentation goes in:
- `docs/ROADMAP.md` — project roadmap & phases
- `docs/DECISIONS.md` — Architecture Decision Records (ADRs)
- `docs/FEATURES.md` — feature specifications
- `docs/ARCHITECTURE.md` — system architecture
- `docs/GLOSSARY.md` — terminology
- `docs/SECURITY.md` — security policies
