# Growth Strategy

**STATUS: RESEARCH REQUIRED**

Prioritize the current micro-market’s binding liquidity constraint. Candidate mechanisms include provider distribution, post-value referral, repeat booking, useful local content, and community partnerships. Each initiative requires baseline, hypothesis, primary metric, contribution economics, guardrails, owner, and stop rule.

The loops below are hypotheses to instrument and validate, not proven Neighborly performance.

## Provider distribution loop

`provider joins → completes verification and creates service/business page → shares it → customers arrive → some become platform users → discover other providers → transactions → authentic reviews/useful content → improved local discovery → additional qualified providers join`

Measure verified activation, qualified visits, match/booking/completion, cross-provider discovery, review integrity, referred providers, and contribution margin. Do not count an unverified page as usable supply.

## Referral loop

`successful transaction/value delivery → eligible user receives relevant referral request/incentive → nearby user joins → transacts in the same local network → density and marketplace quality improve`

Referral asks generally occur after demonstrated value, not immediately after signup. Model incentive cost, caps, self-referral/collusion, reversals, CASL/consent, and completed referred transactions.

## Expansion loop

`active micro-market → sufficient provider density → acceptable match rate → real completed transactions → repeat usage → acceptable time-to-match → acceptable trust/safety → acceptable contribution economics → evaluate adjacent geography/category`

Thresholds are founder-approved and measurement-based; no fixed expansion calendar applies.
