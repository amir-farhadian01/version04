# Marketing Shared Memory

This directory is Git-backed institutional memory for the AI Growth organization. Read [agent governance](../.agents/AGENTS.md) and the [operating model](../docs/MARKETING-OPERATING-MODEL.md) before updating it.

Research is not yet sufficient to select an initial market or assert ICP, positioning, competitor, or baseline-metric conclusions. Unknowns are deliberately marked `STATUS: RESEARCH REQUIRED`.

Empty working directories contain `.gitkeep`; add dated, reviewable Markdown artifacts when real work begins. Do not commit raw contact lists, suppression data, identity documents, secrets, or sensitive personal data.
